# SO-photophisology
A few extra figures for data from the paper: Phytoplankton iron limitation in the Atlantic Southern Ocean driven by seasonal mixed‐layer dynamics.

Project title: Winter 2019 Southern Ocean Phytoplankton Photophysiology - addendum data
Objectives: Provide supplemenatary correlation data
Source: Singh, A., Thomalla, S.J., Fietz, S., Samanta, S., Mtshali, T.N., Roychoudhury, A.N., Viljoen, J.J. and Ryan‐Keogh, T.J., 2025. Phytoplankton iron limitation in the Atlantic Southern Ocean driven by seasonal mixed‐layer dynamics. Limnology and Oceanography
Description: Figure 1: contrasts Δ(Fv/Fm) with σPSII at each station. Figure 2: Correlation analysis of abiotic data with photophyiological data: Figure 3: Correlation analysis of abiotic data with phytoplankton taxa. Diatoms were positively correlated with silicate (ρ = 0.964), nitrate (ρ = 0.893) and phosphate (ρ = 0.883), while showing a strong negative correlation with SST (ρ = −0.964). Conversely, cyanobacteria were positively correlated with SST (ρ = 0.906) and negatively correlated with nitrate and silicate (ρ = −0.906 for both).
Discussion: Results indicate shifts in phytoplankton communities along a temperature and nutrient gradient.
